# PLC Careers

静的なHTML/CSS/JavaScriptで構成した、PLCの国内・海外向けメンバー募集サイト初期版です。法人・雇用主であるかのような表現を避け、募集職種は責任者承認前の「候補」として表示します。

## ローカル起動

ブラウザで `index.html` を開くか、Pythonがある場合は次を実行します。

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000/` を開きます。外部依存・ビルド工程はありません。

## 職種・プロジェクトの編集

`data.js` の `PLC_POSITIONS` に正式募集職種を追加・編集します。公開内容を変更する場合は責任者の確認を取り、報酬・雇用・活動時間を推測で追加しないでください。プロジェクト情報も同ファイルで管理できます。

## 翻訳の編集

`app.js` の `copy`、および `data.js` の `title` / `summary` / `location` / `type` 等の `en`・`ja` 値を編集します。内部IDは変更しないでください。

## Google Forms URL

実在するフォームが承認された後、`data.js` の `PLC_CONFIG.googleFormsUrl` に完全なHTTPS URLを設定します。空文字の間は応募ボタンを押しても送信せず、「準備中」を表示します。架空の成功画面はありません。

## GitHub Pages

このフォルダを独立した `PLC-Recruitment` リポジトリへ登録し、Pagesの公開元をブランチのルート（`/`）に設定します。公開前に、責任者による募集状況、応募フォーム、プライバシー文面、問い合わせ先の承認を取得してください。現時点ではpush・公開していません。

## 注意

PLCは法人化していない独立開発チームです。現時点の参加は無償の協業を想定し、雇用・報酬・採用人数・福利厚生を保証しません。応募受付開始前に個人情報の収集目的、管理者、保存期間を確定してください。
